# IAM and secrets

Names and purposes only. I am not writing account ids, role ARNs, key ids, tokens, or certificate bytes. Where a workflow file contains an ARN, read the file. Do not copy it into a slide.

## People and CI

| Name | Purpose |
| --- | --- |
| AWS profile `GrowRoom` | The local CLI profile `scripts/aws-poc.ps1` exports. Region `us-west-2`. |
| `admin_principal_arn` | The IAM role that receives EKS cluster admin. It must include the path `aws-reserved/sso.amazonaws.com`. |
| `grow-room-gha-plan` | GitHub Actions plan. Read-only, plus state read and write for the lock file. |
| `grow-room-gha-apply` | GitHub Actions apply and destroy. `AdministratorAccess`. Trusted only for environment `aws-poc`. |
| GitHub environment `aws-poc` | The approval gate. It is also what changes the OIDC subject so the apply role trusts the job. |
| GitHub OIDC provider | Created in `infra/aws-poc/bootstrap/main.tf`. |

## Secrets and where they live

| Name | Where | Notes |
| --- | --- | --- |
| `HA_TOKEN` | `.env`, gitignored | Long-lived Home Assistant token. Not in Helm values. |
| `HA_URL` | `.env` | Default inside Compose is `http://homeassistant:8123`. |
| `SENSOR_SOURCE` | `.env` or the chart | `homeassistant` on Compose. `simulator` in the cluster and in CI. |
| `AUDIT_DATABASE_URL` | Environment, or ExternalSecret `audit-db` on EKS | Absent means SQLite. |
| RDS master password | Secrets Manager, generated by RDS | Not in Terraform variables. The gallery says it is not in state. |
| Grafana `adminPassword` | `monitoring/values-k3d.yaml` | Lab only. I am not repeating the value. |
| Argo CD initial admin | Secret `argocd-initial-admin-secret` | Printed once by the bootstrap script. Not committed. |
| Roles Anywhere private key | `C:\src\grow-room-pki\`, not in Git | The CA PEM is the public half. |
| `GITHUB_TOKEN` | GitHub Actions, automatic | Used to push the image. Not an AWS key. |
| `ALERT_EMAIL` | GitHub variable, tfvars, or `$env:ALERT_EMAIL` | The inbox. Not committed. |
| `MY_IP_CIDR` | GitHub variable and tfvars | Your current `/32`. Not a secret, and it goes stale. |
| `ADMIN_PRINCIPAL_ARN` | GitHub variable and tfvars | Contains the account id. Do not paste it into docs. |

`infra/aws-poc/terraform.tfvars` is gitignored. `infra/aws-poc/versions.tf` is not. It contains the state bucket name and the KMS key id. Treat that file as sensitive when you share a screen, even though it is in the public repository.
